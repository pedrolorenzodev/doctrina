# Decisions for Pedro

Gathering Pedro's decisions on open questions (from research maps, a run, a proposal). Last validated: 2026-10-17.

## Steps

1. **Read `DECISIONS.md` first.** For each question, cite the prior decision its recommendation relies on or conflicts with. A recommendation that contradicts a decision is either dropped or presented explicitly as "reopen X".
2. Format by size: up to ~10 questions, numbered points in chat; more, one Artifact page with options, a marked recommendation and the why for each, an optional note per question, and a "copy answers" button that produces text Pedro pastes back.
3. Group by kind (who speaks, which texts, labels, editions, copyright, minor) with the most consequential first.
4. Recommendations respect neutrality: the site never ranks traditions; a recommendation that would need a theological judgement is replaced by a mechanical criterion (e.g. the verbatim-match rule, 2026-10-15).
5. For Pedro's notes on an answer: restate, object where needed, agree, then record. Verify one real case when proposing a criterion.
6. Record the answers in `DECISIONS.md` yourself (format: date · title (Pedro chose), Chosen / Why / Discarded), in Pedro's words for his notes. Open points go to `ROADMAP.md`.
7. Hand Pedro the commit message right after (the design session writes the same files).
