## Agent's calls
1. **Result memory key** is `locale + JSON(address)`, not `addressId`: `addressId` drops the edition (two simplified editions of one locator would share a result) and importing it from `contracts.ts` would put zod in the client bundle. The `id` prop (= `addressId`) stays the key of `simplifier-memory.ts` (streamed once, level). The result memory lives in `use-simplification.ts` because `simplifier-memory.ts` is not in this block's file list.
2. **Message text** comes from `aiErrorBody(code, locale, "simplify")` through `simplifyMessage` in `simplifier-text.ts` (one source, contracts §7); the client derives the text from the code, not from the body's `message`; `retry` is the body's. A failure whose body is not an `AiErrorBody` maps by HTTP status: 429 → `ai_rate_limited`, 403 → `ai_bot_check_failed`, 504 → `ai_timeout`, ≥ 500 → `ai_provider_down`, else `ai_misconfigured`. Network error → `ai_provider_down`; 20 s → `ai_timeout`; a 200 with a malformed body → `ai_misconfigured`.
3. **«Reintentar»** closes the message panel (focus returns to the ring) and starts a new request (the ring goes pending), then the panel opens again with the result. It is the only way that does not keep a half-state inside an open panel.
4. **Message panel keeps the approved header** (selector and label). The selector still moves its indicator and remembers the level, but nothing changes visibly (no crossfade, no request). Disabling it would have changed the approved header.
5. **Level switch** keeps the approved 180 ms cross-fade and height glide; «instant» is read as «no request»: both levels already came in one response.
6. **Tooltip** shows «Simplificando…» while pending; the button's `aria-label` stays «En palabras simples» (the name must not change while it works; `aria-busy` and the live region carry the state).
7. **Escape** cancels a pending request (the panel's Escape already closed an open one).
8. **Visibility `hidden`** = `display: none` on the ring unless the panel is open or pending (a hidden ring must not be focusable). Consequence for S-ENTRY: after Escape or «Ocultar» with the switch off, focus cannot return to a ring that is not shown.
9. **Prefetch** runs once per paragraph and page view, only with `(pointer: fine)`, on pointer enter and focus. With the fake provider the cache-only route always answers 200, so a hover makes the press instant; the specs mock the probe (204) when they need the pending state.
10. **English status strings** added («Generated by AI», «Reviewed»; pending «Simplifying…», retry «Try again»).
11. **Wording flag for INT and Pedro:** the contract's simplifier table keeps the chat text for `ai_bot_check_failed`: «No pudimos comprobar que la pregunta viene de una persona…». It says «pregunta» on a simplifier panel. I did not change a contract text; propose a `simplifyOverrides` entry in `errors.ts` (block F's file).
