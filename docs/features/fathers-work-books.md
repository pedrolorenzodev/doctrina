## What «exactly the Bible's logic» means in code (to build, blocks)
1. **Data:** per-work book table derived from the locator's first part (no new corpus files); book titles as the editions give them («Libro 1»).
2. **Tree:** the work becomes a branch with a `ChapterGrid`-style grid of book numbers under its Father, the current book marked, as the Bible's books do.
3. **Stream:** the work's page mounts books as `section[data-stream-chapter]` with the active-chapter store, URL and title following the scroll, previous/next arrows crossing books (`reader-stream.tsx`, `active-chapter.ts`).
4. **Read mark per book:** the 4 px dot of the Bible chapters (`read-chapter-store`), with the same floating button. **Depends on the Fathers' «read dot on each work» item (ROADMAP «Now»), not built yet:** build that first for whole works, then per book.
5. **Specs:** the Bible's stream specs adapted (boundary crossing without a jump, tree follows the scroll, read mark per book).
**Decided 2026-10-29 (Pedro):** one route per book (`/historia/obras/<work>/<book>`, the division in the hash, as the Bible's chapters), every work that fits. **Still open:** whether citations such as «Contra las herejías 3.12.5» keep opening the work at that division (yes by default); Cyril of Jerusalem's lectures as a grid of 24.
