Legend: CONFIRMED (string, order, punctuation and locator found as stated) / WRONG (needs a correction, given with its source and the tag it should get) / UNCONFIRMABLE (could not be settled, reason given).

Method: Holy See pages and BookOfConcord.org pages fetched with `curl -sL -A "Mozilla/5.0"`, converted to text, footnote markers removed, whitespace and curly quotes normalised, and each segment (split at `[…]`) searched as a case-sensitive exact string, in order; then the page text after the last segment was read to judge the cut. For archive.org items the `_djvu.txt` OCR was matched letter by letter (case kept) and every non-trivial item was read on the page image (`https://archive.org/download/<id>/page/n<leaf>_w1400.jpg`, viewed with the Read tool). A match in OCR only is not promoted beyond what the record's tag says.
