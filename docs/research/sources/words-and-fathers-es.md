## Part 1 · Spanish glosses (the decided route: own, AI-drafted, automatic)

- `glosses-es.json` is one table `english → spanish`, written by the agent (Claude Sonnet 5.5) from STEPBible's English glosses, **never reviewed by a person**: `status` says so. It is applied by the generator three ways: (a) the lexicon `gloss`, (b) the Greek word `en`, (c) each `/`-part of a Hebrew word's `en`. A string absent from the table is split on `: `, `/` and `;` and each piece looked up; a trailing ` [the]`/` <the>` is handled; a capitalised string falls back to its lowercase entry. If any piece is unknown the Spanish is **absent**, never guessed. The Greek article `the`/`The` is rendered from its morph code (el/la/los/las). **Proper names** (lexicon pos «proper name…»): when no table entry exists the Spanish equals the English name (listed Spanish forms: only where I wrote them).
- Coverage (the UI must fall back to English, labelled): Greek lexicon `glossEs` 4,410/5,583 entries (99.1 % by NA28 tokens), Hebrew lexicon 8,724/11,442 (97.7 % by tokens, because names default to the English form); words with `es`: Greek 115,923/137,919 (84.1 %), Hebrew 231,617/305,648 (75.8 %). The remaining gaps are long-tail inflected forms (e.g. «having been spoken»), plural 2nd-person verbs (deliberately empty) and rare words; `build_words.py --worklist <dir>` writes the missing pieces by frequency.
- Limits to say in the UI/attribution: context-free glosses («of you» → «de ti» cannot know singular or plural); Hebrew name forms default to English; the Spanish of a Greek/Hebrew `en` that is a clause is literal.
