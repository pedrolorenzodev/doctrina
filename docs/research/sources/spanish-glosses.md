## Short answer

1. **One CC BY 4.0 Spanish gloss source does exist**: *Lexicon Omnium Gentium* (E. Timothy Uy, Loqu8 Inc.), Zenodo DOI 10.5281/zenodo.19099634, version 1.0.0, 18 March 2026: a lexicon keyed to Strong's numbers for all 19,570 Hebrew and Greek entries, in 28 languages including Spanish (547,756 definitions in all; the record gives no per-language count), **generated by a large language model (MiniMax M2.5) from «curated English source definitions»**. Licence field: «Creative Commons Attribution 4.0 International». `[verified: Zenodo record page via the fetch tool, 2026-11-01; the licence and description lines are the record's own]`.
2. **It is not a clean answer to «is there a CC BY Spanish source»**, because: (a) the record does not name the English source definitions or their licences, so whether the CC BY label can lawfully cover a translation of them is unknown (Strong's own definitions are public domain; other lexica may not be); (b) the Spanish is machine translation, the same kind of output Doctrina would produce itself from STEPBible's glosses; (c) it is a 2026 dataset with one author and a paper only «submitted»; (d) the API and the full description could not be read (`zenodo.org/api/records/…` returned 403).
3. **No other CC BY or public-domain Spanish gloss set was found** (list below). In particular, OpenGNT's Spanish layer has **no licence stated on the README page**, so the premise «OpenGNT's CC BY-SA Spanish glosses» in DECISIONS 2026-11-01 is not confirmed: the README states CC BY-SA 4.0 for the main OGNT text, and says nothing for the Spanish literal translation (see row 1).
4. **The agent's recommendation** (a proposal, Pedro decides): keep the decided route (own AI-drafted Spanish glosses from STEPBible's CC BY English glosses, labelled automatic), and do not depend on *Lexicon Omnium Gentium* unless its author confirms the English source and its licence; it could serve as a cross-check of the model's output if that is cleared. Ask the author («Uy, Loqu8») one question before using it: *which English dictionary are the source definitions, and under what licence?*
