## Lessons learned (do not relearn)
- **Measure durations from transcripts, never from when a report is read** (I got it wrong twice); the weekly counter includes the shared account's owner; one point ≈ $6.9 of equivalent cost; plan estimates ran 1.3–3× high; Claude sessions' own usage self-reports are partial.
- **Merging:** a loop copying from several duplicates let stale stubs overwrite LIM's files once; always copy by explicit per-owner lists; a duplicate that is mid-task (its next task already started) must not be merged; an `rsync` with a mis-quoted exclude list overwrote a session's files; never edit the real tree while a kit has unapplied blocks; check the real file against `git show HEAD:<file>` before copying over it (clean = safe).
- **Prompts and the hook:** the git-write hook blocks any shell command whose text contains git write verbs, even inside a heredoc that writes a prompt file: write prompt files with the file-writing tool and `cat` them together; prompts via `pbcopy < file`; the sessions' cross-session messages (`SendMessage`) work for live sessions and are the way to give them tasks.
- **Waiting:** never `sleep` or poll; run long builds in the background and answer when the notification arrives.
- **Tests and ports:** Playwright reuses any server on 3100: a session once hit Pedro's real review server (and spent real money); review servers use 3100/3101, sessions use `E2E_PORT` with a free port and `AI_PROVIDER=fake`.
- **Product lessons:** a keyword router in front of the AI swallowed free text; «richness by construction» (top-up to a floor) pads unless relevance gates it; a verbatim-quote check must normalise Unicode (NFC: Greek tonos vs oxia broke a whole paragraph); a harder rewrite raises doctrinal drift and only a strong judge catches it; fidelity judges have ≈ 1/3 false alarms (safe: they cost a regeneration); the model must never translate quotes (unverifiable); the first attempt must succeed (two parallel candidates); the Anthropic credit and the Claude weekly counter are different budgets (bulk translation on the credit is cheap in points).
- **How Pedro works:** he tests in Chromium «Dia»; he reviews a few things at a time and answers by quoting; never blame Safari; replicate approved artifacts exactly (add nothing, remove nothing; flag conflicts); UI without a precise spec gets a proposal Artifact first; he wants every message short.
