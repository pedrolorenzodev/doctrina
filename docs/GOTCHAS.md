# Gotchas

Traps that bite, and the why of every guard in the code. Format: **what** bites · **why** · **where**. Only verified traps; delete an entry when the trap leaves the code.

## Next.js and tooling

- **`tsc --noEmit` alone fails with `Cannot find name 'LayoutProps'`** on a clean clone or after deleting `.next`. · Next generates the global route types (`LayoutProps`, `PageProps`) into `.next/types`. · `package.json` → `typecheck` runs `next typegen` first; always use `npm run typecheck`.
- **A root `app/` folder makes Next silently ignore `src/app`.** · Next only looks in `src/` when there is no root `app/` (tested 2026-10-05: routes under `src/app` vanished from the build). · Repo root: never create `app/` (or `pages/`) there.
- **`proxy.ts` (formerly `middleware.ts`) must live inside `src/`.** · Next docs, `03-file-conventions/src-folder.md`. · `src/proxy.ts` when it exists.
- **Moving code paths breaks aliases and tool globs.** · `@/*` resolves to `./src/*`; any `include`, ESLint or tool path pointing at root `app/`, `components/` or `lib/` is stale. · `tsconfig.json`, `eslint.config.mjs`. Tailwind 4 needs no `content` config; if an old config with `content` ever appears, prefix `src/`.
- **`next build` warns "Next.js ignored package-lock.json in /Users/pedrolorenzo/Desktop/dev".** · A stray lockfile exists one level above the repo. Harmless: Next picks this repo. Don't set `turbopack.root` to silence it. · `~/Desktop/dev/package-lock.json` (outside the repo).
- **ESLint also lints `data/scripts/*.mjs`** (and `handoff/` while it exists): today only `no-unused-vars` warnings. · The flat config lints every JS file not ignored. · `eslint.config.mjs`.

- **Node 23 instead of 24 in a new shell.** · nvm's global default is still 23 (left as is); the repo pins 24 in `.nvmrc` and `engines`. · Run `nvm use` in the repo before `npm`; `npm install` on 23 warns about `engines`.
- **A lint rule change can silently stop catching what it should.** · Selectors and regexes in `eslint.config.mjs` fail open (no match, no error). · `tools/check-lint-rules.mjs` holds one fixture per forbidden edge and allowed case; add one with every rule change. It runs inside `npm run lint`.
- **Tailwind arbitrary values are caught only in string literals of `.tsx` files.** · The lint checks literals and template parts, not strings assembled in `.ts` helpers. · `eslint.config.mjs`; keep class strings in `.tsx`.

- **The English-names check only knows the words in its list.** · `tools/spanish-words.mjs` is a denylist: a Spanish word not in it passes, and English-looking Spanish words (`general`, `final`, `color`) are deliberately left out. · Add each miss to the list and a fixture to `tools/check-english-names.mjs` or `tools/check-lint-rules.mjs`.

- **`npm run e2e` needs a build and port 3100.** · The config starts `next start`; without a fresh `npm run build` the specs test stale output. Locally it reuses a server already on 3100; in CI it always starts one. · `playwright.config.ts`.
- **Animation assertions use `getAnimations()`, not sampled frames.** · Frame sampling failed under parallel load; checking `transitionProperty` right after the click is deterministic and also catches the `translate`-versus-`transform` trap. · `e2e/citation-window.spec.ts`, `e2e/sidebar.spec.ts`.

## Git and environment

- **`.env*` in `.gitignore` would also ignore `.env.example`.** · The scaffold's ignore pattern is broad. · `.gitignore` → `!.env.example` re-includes it; keep that line below `.env*`.
- **`tools/review-page/check.mjs` requires `playwright-core`** (`process.env.PLAYWRIGHT_CORE || 'playwright-core'`); since 2026-10-23 the repo installs it through `playwright`. Blocked Google Fonts requests show as 4 "Failed to load resource" errors per run: expected. Template markers in `shell.html` are `__DATA__` and `__APP__`. · `tools/review-page/`.
- **The git hook matches the whole command text, not just the command.** · It is a regex over the Bash string: `echo 'run git push later'` is blocked too, and so is `git restore --staged` (unstaging). It also blocks `add`, `rm`, `mv` and `stash` (2026-10-17): `git rm --cached` once slipped through and staged a deletion, while the undo was blocked. Because it matches text, a heredoc or script passed inline that merely mentions those commands is blocked too: write the script to a file first. Rephrase the command or let Pedro run it. · `.claude/hooks/block-git-writes.mjs`.

## Data scripts

- **`data/scripts/build_bibles.py` is the exception below: adapted, run it with `python3 -I` from outside the repo.** · Downloads go to `data/raw/src/bibles/`, verses (keyed by OSIS, each edition in its own numbering: DRA is Vulgate, RV1909 and KJV put psalm titles inside verse 1, KJV keeps its ¶ marks) to `data/corpus/bibles/` (both gitignored), the manifest with URL, date and sha256 to `data/sources/bibles.json` (tracked). eBible answers 403 without a User-Agent; its VPL files use old book codes (`JOH`, `EZE`, `SOL`…). · `data/scripts/build_bibles.py`.
- **The other `data/scripts/` are not adapted to this repo: don't run them.** · `build_site_john6.py` and `build-eucharist.mjs` write to v2's `src/content/data/`, `port-v1.mjs` writes `src/content/sources.ts` and `traditions.ts` (v2 layout), and `build-eucharist.mjs` reads `objection-headlines.json` from there (it now lives in `data/site/`). The Python builders need the original downloads in `data/raw/src/` (gitignored; copy from `~/Desktop/dev/doctrina-v2/data/raw/src/` or re-download). `build-eucharist.mjs` and `port-v1.mjs` use paths relative to the working directory, so they run from the repo root. · `data/scripts/`.

## UI foundation

- **Optical size does nothing unless the font loads the `opsz` axis.** · `next/font/google` ships only the weight axis by default; the DESIGN scale sets `"opsz" n` per role (`opsz-72`, `opsz-36` utilities). · `src/lib/fonts.ts`: Newsreader and Source Serif 4 declare `axes: ["opsz"]`; a new serif face needs the same.
- **Theme tokens must live under `[data-theme="dark"]`, never under `prefers-color-scheme`.** · The reader's toggle overrides the device setting (DESIGN §1 Theme); the attribute is set before first paint by an inline script that reads `doctrina-theme` from `localStorage`, else the device setting. · `src/app/globals.css`, `src/lib/theme.ts` (the toggle in B3 must write the same key; `tools/check-theme-script.mjs` runs in `npm run lint`).
- **The page texture layer is `position: fixed` at `z-index: 0`; content must sit in a `relative z-1` wrapper.** · A multiply layer above content would darken text. · `src/app/layout.tsx`, `texture-page` utility.
- **`next/font` adds a size-adjusted fallback to the family name (`Newsreader, "Newsreader Fallback", …`).** · Intended (less layout shift); it makes the computed `font-family` differ from the proposal's while glyphs are pixel-identical. · Pixel checks against `site-clean/`: compare glyphs, not that string.
- **`error.tsx` receives `retry`, not `reset`, in this Next (16.3).** · Docs `03-file-conventions/error.md`; the usual training-data prop does nothing here. · `src/app/[lang]/error.tsx`, `src/app/global-error.tsx`.
- **With `experimental.globalNotFound`, every `notFound()` and every unmatched URL renders `src/app/global-not-found.tsx`; a `not-found.tsx` under `[lang]` is never used.** · The root layout sits under a dynamic segment, so Next skips it for 404s (tested 2026-10-24: a nested `not-found.tsx` came back as the unstyled `__next_error__` document). The page therefore shows both languages. · `src/app/global-not-found.tsx`, `next.config.ts`.
- **`dynamicParams = false` on `[lang]/layout.tsx` makes Next log `Error: Internal: NoFallbackError` for each unknown locale (`/fr`).** · Harmless: the response is the styled 404. Without it, `/fr` returns the unstyled `__next_error__` page. · `src/app/[lang]/layout.tsx`.
- **`global-error` and `global-not-found` render outside the locale layout.** · They bring their own `<html>`: they use `Document` (theme script, fonts, texture) and `globals.css`, and show both languages (no `lang` param exists there). · `src/components/document.tsx`.
- **`tools/check-theme-script.mjs` imports `src/lib/theme.ts` directly (Node 24 strips the types).** · The package has no `"type": "module"`, so Node warns; the lint script passes `--disable-warning=MODULE_TYPELESS_PACKAGE_JSON`. · `package.json` → `lint`.
- **A soft navigation between `[lang]` roots drops the `data-theme` attribute on `<html>`.** · React reapplies the server's `<html>` props (no theme) when the root layout changes params. · The language switch is a plain `<a>` (`src/features/shell/language-switch.tsx`); any future link that changes locale must be one too.
- **View transition for the theme: `html.theme-switching` and its CSS must stay together.** · The class turns every CSS transition off while the circle reveals, and `::view-transition-old/new(root)` need `animation: none; mix-blend-mode: normal`, or the browser cross-fades instead of sweeping. · `src/features/shell/theme-toggle.tsx`, `src/app/globals.css`.
- **`texture-layer` needs a positioned element and a layer above its content.** · The noise is an absolutely placed `::after`; the element must be `sticky`, `relative` or `absolute`, and its direct children are lifted to `z-index: 1` by the utility. · Top bar now; every opaque sticky surface later (DESIGN §1 Texture).
- **`html` has `line-height: normal`, not Tailwind's 1.5.** · The clean site was built on the browser default; with 1.5 every unspecified line came out taller (logo 34 px instead of 23). · `src/app/globals.css`, base layer; roles whose DESIGN row gives a line height set it in their `--text-*` token.
- **Never `whitespace-nowrap` on citation labels.** · Labels like «Mysterium fidei 10, 24, 46» are wider than a phone; the non-breaking space before each number already keeps locators together. A nowrap on a source span made the page 840 px wider at 360 px. · `teach-section.tsx`.
- **Reveal states live in `data-rv` on the list items, set by `list-motion.ts`, not by React.** · `armed` (opacity 0) is released when the item passes above the viewport; React must not render `data-rv`. · `src/lib/list-motion.ts`, `globals.css`.
- **Tailwind v4 `translate-*`, `scale-*` and `rotate-*` set the `translate`, `scale` and `rotate` properties, not `transform`.** · A transition on `transform` does not animate them (the drawer slid in 60 ms, the window did not rise). Use `transition-transform` (covers the four) or list `translate` explicitly. · `drawer-motion`, `window-motion` in `globals.css`.
- **The citation window panel is always mounted, closed.** · Mounting it already open skips the enter transition; its content is rendered only when a view exists. · `citation-window.tsx`.
- **Esc goes through `escape-stack.ts`, never a local listener.** · Priority decides which layer closes (search, reader, window, drawer). · `src/lib/escape-stack.ts`.
- **The window's position is derived, not stored clamped.** · The remembered point is clamped at render from the viewport, so shrinking and growing the window gives the original place back; clamp with `clampWindow`, never by hand. · `window-position.ts`, `tools/check-window-position.mjs`.
- **`texture-layer` rounds its overlay with `border-radius: inherit`.** · Otherwise a rounded panel shows square corner marks. · `globals.css`.
- **Locator text goes through `nbspBeforeDigits`.** · A line must never break before the number of a locator («Catecismo 1375»); `PageLink` and `InPlaceLink` apply it to string children, so a label passed as JSX or built by hand needs the call. · `src/lib/locator.ts`.
- **`mark-external-flush` must come after `mark-external` in the class list's effect.** · Both set `::after` margin; the flush one wins only because Tailwind emits it later (tested: 0 px). A button with a flex `gap` uses the flush one; a link inside text the other. · `globals.css`, `action.tsx`.
- **Every nested scroller needs `data-lenis-prevent`.** · Lenis owns wheel scrolling of the page; without the attribute a wheel over the sidebar, the citation window, search, the reader or a sideways strip scrolls the page instead. Done: the sidebar. · Add it with each of those components.
- **The scroll offset has one source.** · `scrollOffset()` in `src/lib/scroll.ts` reads `--spacing-top` and `--spacing-scroll-offset`, the same two tokens as `scroll-padding-top`; a literal in either place makes jumps and native anchors land differently. · `src/lib/scroll.ts`, `globals.css`.
- **Ruler ticks use a `backwards` animation fill.** · `forwards` or `both` would freeze `transform: scaleX(1)` and the hover bulge would never show. · `tick-fill` in `globals.css`.
- **The sidebar's expansion state lives in the DOM, not in React.** · «Despliegue» animates `hidden` and height imperatively; a React prop that changes (`hidden`, `aria-expanded`) would hide a branch before its exit animation ends. Those props are computed once (`initiallyOpen`) and never change; `ul[data-branch][data-open]` is the truth and `settleDescendants` reconciles after a cancelled animation. · `src/features/shell/sidebar.tsx`, `tree-motion.ts`.
- **`usePathname()` returns the internal path on the server and the visible one in the browser for a rewritten URL.** · `/es/doctrinas/eucaristia/catolica` renders as `/es/doctrines/eucharist/catholic`; matching only one made the current row disappear on first render. · `TreeNode.href` and `TreeNode.route` are both indexed.
- **The drawer's open state is derived from the pathname.** · It stores the path it was opened at, so a navigation closes it with no effect setting state. · `src/features/shell/drawer.tsx`.
- **A closed drawer stays unfocusable through `visibility`, not `inert`.** · `max-lg:invisible` with a 240 ms delay on close (`drawer-motion`), so the slide stays visible and Tab cannot reach it. · `globals.css`, `sidebar.tsx`.
- **`html` carries the page background.** · Without it the rubber-band area past the page edge showed the browser's white (Pedro, 2026-10-24). · `globals.css`, base layer.
- **`src/content/registry/*` and `pages/*/catholic.es.ts` were generated, then belong to us.** · Rerunning `convert-dossier.mjs` overwrites hand edits and rebuilds the registry from only the doctrines named on the command line. · Run it only for a doctrine not yet imported, and merge by hand.
- **Node resolves `@/` only through `tools/alias-loader.mjs`.** · tsconfig paths mean nothing to plain Node; tools that import `src/` need `--import ./tools/register-alias.mjs`. Value imports inside `src/content` must use `@/`, never `../`. · `package.json` → `lint`.
